Antigravity 무료 AI 자동셋팅

Antigravity 데스크톱과 Antigravity IDE에 OpenRouter 무료 모델을 넣는 절차. 작성일 2026-11-09 (한국 시간). API 키 값은 이 문서에 없다.

두 프로그램의 기본 모델 목록은 Google 계정 모델만 보여 준다. 설정 파일에 임의 키를 적어도 요청은 OpenRouter로 가지 않는다. 같은 무료 키를 쓰려면 antigravity-add-model 이 로컬 프록시를 붙인다. 이 도구는 설치본을 수정하고, 실패하면 백업으로 되돌린다. IDE 쪽은 확인된 2.5.5와 2.6.0에서 동작한다.

1. PC에서 실행

Node.js 22.13 이상과 Git이 필요하다. Antigravity와 Antigravity IDE를 닫은 뒤 PowerShell에서 실행한다. 스크립트는 이름이 Antigravity로 시작하는 프로세스를 종료하고, Claude Code에 저장된 OpenRouter 키를 다시 사용한다. 키 값은 화면에 나오지 않는다.

Set-ExecutionPolicy -Scope Process Bypass
irm "https://raw.githubusercontent.com/haengsun1009-ux/github-desktop/cursor/free-ai-setup-guides-7255/free-ai-setup/setup-antigravity-free.ps1" | iex

정상 출력에는 KEY_SET=True, APPLIED= 뒤에 설치 폴더, IMPORT_FILE= 경로가 있다. 설치 폴더를 못 찾으면 INSTALLS=0 이다. 그 경우 프로그램 바로 가기의 대상 폴더를 확인한다.

2. 모델 가져오기

스크립트는 모델 관리 브라우저를 연다. Import 를 누르고 출력된 openrouter-free-import.json 을 고른다. 가져오기가 끝나면 그 파일은 키를 평문으로 담고 있으므로 삭제한다.

목록은 Claude Code에 넣은 무료 모델 11개다. 각 모델이 막히면 openrouter/free 로 넘어간다. 관리 화면에서 Test connection 은 연결만 확인하고, 짧은 응답까지 보려면 Test generation 을 쓴다.

Antigravity를 다시 연 뒤 채팅의 모델 선택에서 OpenRouter Free, Gemma 4, Nemotron 같은 저장된 이름이 보이면 연결이 끝난 것이다. Google 로그인 모델은 그 옆에 그대로 남는다. IDE는 스크립트가 띄운 프록시가 켜져 있는 동안 이 목록을 쓴다. 일반 바로 가기만 열면 프록시가 없어 사용자 모델이 빠질 수 있다.

3. 버전이 맞지 않을 때

SKIPPED= 만 있고 APPLIED= 가 비어 있으면 설치된 버전이 이 도구의 확인 범위를 벗어난 것이다. 그 설치본은 수정하지 않는다. Antigravity IDE에서는 확장 Cline(saoudrizwan.claude-dev)을 설치하고 다음을 입력한다.

  • API Provider: OpenAI Compatible
  • Base URL: https://openrouter.ai/api/v1
  • API Key: Claude Code에 저장된 OpenRouter 키
  • Model ID: openrouter/free

Cline 패널의 모델은 IDE 기본 에이전트 목록과 따로다. 데스크톱 앱의 모델이 패치 뒤에도 비어 있으면, 추가 도구 폴더에서 언어 서버 패치를 확인한 뒤에만 적용한다.

cd $env:USERPROFILE\antigravity-add-model
.\deploy.ps1 --check --patch-language-server
.\deploy.ps1 --patch-language-server

4. 되돌리기

프록시를 끄고 원래 설정으로 되돌릴 때 설치 폴더를 넣는다.

cd $env:USERPROFILE\antigravity-add-model
npm run proxy:stop
npm run ide:restore -- --resources "C:\path\to\Antigravity IDE"
.\deploy.ps1 --restore --resources "C:\path\to\Antigravity"

Antigravity를 업데이트한 뒤에는 1장의 스크립트를 다시 실행한다. 업데이트는 붙여 둔 연결을 지울 수 있다.
