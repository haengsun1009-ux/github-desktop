클로드 무료 AI 자동셋팅

Claude Code를 OpenRouter 무료 모델로 연결하는 절차. 최신 버전은 2026-11-06 기준 2.1.319. 작성일 2026-11-09 (한국 시간). API 키 값은 이 문서에 없다.

PC의 D:\ai\AI 셋팅\free AI 방법 은 이 작업 환경에 없다. 이 파일을 그 폴더에 클로드 무료 AI 자동셋팅.html 로 복사한다. settings.json 은 커밋하지 않는다. 그 파일에 키가 들어간다.

1. 무엇을 연결하는가

Claude Code 프로그램을 OpenRouter로 보낸다. 답변 모델은 Sonnet 5.5가 아니라 OpenRouter 무료 모델이다. 키 모음 파일에서 이 설정에 쓰는 값은 OpenRouter 무료 키 한 줄뿐이다. Anthropic 키(sk-ant-)는 그 파일에 없다.

키 파일에 함께 있는 OpenAI, Gemini, Grok, NVIDIA, Ollama, OpenCode Zen, Context7 키는 Claude Code의 /model 목록에 줄을 추가하지 않는다. 이 세션의 요청은 https://openrouter.ai/api 로만 간다. Context7 키는 문서 검색용이다.

OpenRouter 무료 키는 호출 확인을 통과했다. 계정은 무료 티어이고, openrouter/free 시험 요청은 HTTP 200으로 nvidia/nemotron-3.5-super-vl:free 에 라우팅되었다.

2. 자동 설정

Claude Code는 프로젝트 .env 를 읽지 않는다. 사용자 설정 파일 %USERPROFILE%\.claude\settings.json 의 env 에 넣는다. 이 PC 경로는 C:\Users\USER\.claude\settings.json 이다.

공식 연결 규칙은 다음이다.

  • ANTHROPIC_BASE_URL = https://openrouter.ai/api
  • OpenRouter 키는 ANTHROPIC_AUTH_TOKEN 에 넣는다.
  • ANTHROPIC_API_KEY 는 빈 문자열로 둔다. 값이 있으면 Claude 계정 인증과 겹친다.

PowerShell에서 첫 줄의 경로만 키 파일 위치로 바꾼 뒤 실행한다. 키 값은 화면에 나오지 않는다.

$keyFile = "$env:USERPROFILE\Downloads\Context7 Secret Key.txt"
$raw = Get-Content -Raw -Encoding UTF8 $keyFile
if ($raw -notmatch 'sk-or-v1-[A-Za-z0-9]+') { throw "OpenRouter key not found in $keyFile" }
$key = $Matches[0]

$dir = Join-Path $env:USERPROFILE ".claude"
$path = Join-Path $dir "settings.json"
if (-not (Test-Path $dir)) { New-Item -ItemType Directory -Path $dir | Out-Null }
$settings = if (Test-Path $path) { Get-Content -Raw -Encoding UTF8 $path | ConvertFrom-Json } else { [pscustomobject]@{} }
if (-not $settings.env) { $settings | Add-Member -NotePropertyName env -NotePropertyValue ([pscustomobject]@{}) -Force }
function Set-EnvValue($obj, $name, $value) {
  if ($obj.PSObject.Properties.Name -contains $name) { $obj.$name = $value }
  else { $obj | Add-Member -NotePropertyName $name -NotePropertyValue $value }
}
Set-EnvValue $settings.env "ANTHROPIC_BASE_URL" "https://openrouter.ai/api"
Set-EnvValue $settings.env "ANTHROPIC_AUTH_TOKEN" $key
Set-EnvValue $settings.env "ANTHROPIC_API_KEY" ""
Set-EnvValue $settings.env "ANTHROPIC_MODEL" "openrouter/free"
Set-EnvValue $settings.env "ANTHROPIC_DEFAULT_SONNET_MODEL" "google/gemma-4-31b-it:free"
Set-EnvValue $settings.env "ANTHROPIC_DEFAULT_HAIKU_MODEL" "nvidia/nemotron-3.5-lightning:free"
Set-EnvValue $settings.env "ANTHROPIC_DEFAULT_OPUS_MODEL" "nvidia/nemotron-3-ultra-550b-a55b:free"
Set-EnvValue $settings.env "ANTHROPIC_DEFAULT_FABLE_MODEL" "nvidia/nemotron-3.5-super-vl:free"
Set-EnvValue $settings.env "ANTHROPIC_CUSTOM_MODEL_OPTION" "openrouter/free"
Set-EnvValue $settings.env "ANTHROPIC_CUSTOM_MODEL_OPTION_NAME" "OpenRouter Free"
Set-EnvValue $settings.env "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY" "0"
$settings | ConvertTo-Json -Depth 20 | Set-Content -Encoding utf8 $path

$check = Get-Content -Raw -Encoding UTF8 $path | ConvertFrom-Json
"FILE=" + $path
"BASE=" + $check.env.ANTHROPIC_BASE_URL
"MODEL=" + $check.env.ANTHROPIC_MODEL
"TOKEN_SET=" + [bool]$check.env.ANTHROPIC_AUTH_TOKEN
"API_KEY_EMPTY=" + ($check.env.ANTHROPIC_API_KEY -eq "")
정상 출력은 BASE=https://openrouter.ai/api, MODEL=openrouter/free, TOKEN_SET=True, API_KEY_EMPTY=True 다. PowerShell의 $env:ANTHROPIC_API_KEY 가 비어 KEY_SET=False 로 보여도, 키는 ANTHROPIC_AUTH_TOKEN 에 있으면 된다.

3. 설정이 되었는지 확인

/status 는 Claude 웹 채팅이나 앱 대화창에서 동작하지 않는다. PowerShell에서 Claude Code 터미널을 연 다음에만 동작한다.

claude

화면이 터미널 전체 화면으로 바뀌고 아래에 입력줄이 생기면 /status 를 입력한다. 연결된 세션은 이렇게 나온다. 이 PC에서 실제로 확인된 값이다.

Version:             2.1.227
Auth token:          ANTHROPIC_AUTH_TOKEN
Anthropic base URL:  https://openrouter.ai/api
Model:               gemma4:e4b
Setting sources:     User settings

Auth token 과 Anthropic base URL 두 줄이 맞으면 OpenRouter 연결은 된 것이다. Setting sources: User settings 는 settings.json 에서 읽혔다는 뜻이다.

예전에 Claude 계정으로 로그인했다면, Claude Code 안에서 /logout 을 한 번 실행하고 프로그램을 완전히 끈 뒤 새 PowerShell에서 claude 를 다시 실행한다. Auth token 이 ANTHROPIC_API_KEY 로 나오거나 Login method에 Claude 계정이 보이면 무료 키가 아직 적용되지 않은 것이다.

파일만 보려면 PowerShell에서 다음을 실행한다. 키 값은 출력되지 않는다.

$s = Get-Content "$env:USERPROFILE\.claude\settings.json" -Raw | ConvertFrom-Json
"BASE=" + $s.env.ANTHROPIC_BASE_URL
"MODEL=" + $s.env.ANTHROPIC_MODEL
"TOKEN_SET=" + [bool]$s.env.ANTHROPIC_AUTH_TOKEN

4. gemma4:e4b 와 무료 모델

/status 의 모델 gemma4:e4b 는 OpenRouter의 Gemma 4다. 짧은 이름만으로는 무료 버전인지 구분되지 않는다. 가격이 0인 ID는 끝에 :free 가 붙는다.

모델 ID용도
openrouter/free그때그때 무료 모델을 자동 선택
google/gemma-4-31b-it:freeSonnet 자리에 넣을 일반 모델
google/gemma-4-26b-a4b-it:free같은 계열의 무료 Gemma. :free 가 없으면 유료다
nvidia/nemotron-3.5-lightning:freeHaiku 자리에 넣을 빠른 모델
nvidia/nemotron-3-ultra-550b-a55b:freeOpus 자리에 넣을 큰 모델
nvidia/nemotron-3.5-super-vl:freeFable 자리. 자동 라우터가 시험 호출에서 고른 모델

유료 한도가 끝나도 Claude 구독 세션이 이 무료 모델로 자동 전환되지는 않는다. 무료로 이어가려면 이 설정으로 연 Claude Code 세션을 쓴다.

5. 최신 버전으로 올리고 /model 목록을 늘리기

지금 설치된 버전은 2.1.227이다. 2026-11-06 기준 최신은 2.1.319 다. /model 에 무료 모델을 여러 줄로 넣는 modelPicker 는 2.1.242부터 동작하므로, 2.1.227에서는 목록이 gemma4:e4b 한 줄로 남을 수 있다.

Claude Code 창을 모두 닫고 PowerShell에서 업데이트한다.

claude update
claude --version

claude update 가 실패하면 네이티브 설치 명령으로 다시 받는다.

irm https://claude.ai/install.ps1 | iex
claude --version

버전이 2.1.242 이상이면, 기존 OpenRouter 키는 유지한 채 모델 목록만 추가한다.

$path = "$env:USERPROFILE\.claude\settings.json"
$s = Get-Content -Raw -Encoding UTF8 $path | ConvertFrom-Json
$models = @(
  @{ model = "openrouter/free"; label = "OpenRouter Free"; description = "무료 모델 자동 선택" },
  @{ model = "google/gemma-4-31b-it:free"; label = "Gemma 4 31B"; description = "무료" },
  @{ model = "google/gemma-4-26b-a4b-it:free"; label = "Gemma 4 26B"; description = "무료" },
  @{ model = "nvidia/nemotron-3-ultra-550b-a55b:free[1m]"; label = "Nemotron 3 Ultra"; description = "무료, 100만 컨텍스트" },
  @{ model = "nvidia/nemotron-3.5-super-vl:free[1m]"; label = "Nemotron 3.5 Super"; description = "무료, 100만 컨텍스트" },
  @{ model = "nvidia/nemotron-3.5-lightning:free[1m]"; label = "Nemotron 3.5 Lightning"; description = "무료, 빠름" },
  @{ model = "nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free"; label = "Nemotron 3 Nano"; description = "무료" },
  @{ model = "cohere/north-mini-code:free"; label = "North Mini Code"; description = "무료, 코드" },
  @{ model = "recursive/flint-v1.0:free"; label = "Flint"; description = "무료" },
  @{ model = "xingchen-agi/xing4.0-29b-a4b:free"; label = "Xing 4.0"; description = "무료" },
  @{ model = "dots-studio/dots-3-note-preview:free"; label = "Dots3 Note"; description = "무료" }
)
$options = foreach ($item in $models) { [pscustomobject]$item }
$picker = [pscustomobject]@{ replaceBuiltInOptions = $true; options = $options }
if ($s.PSObject.Properties.Name -contains "modelPicker") { $s.modelPicker = $picker }
else { $s | Add-Member -NotePropertyName modelPicker -NotePropertyValue $picker }
$s | ConvertTo-Json -Depth 20 | Set-Content -Encoding utf8 $path

Claude Code를 완전히 종료한 뒤 새 PowerShell에서 claude 를 실행하고 /model 을 연다. 위 11개 무료 모델이 보여야 한다. [1m] 은 Claude Code에 컨텍스트가 100만 토큰임을 알리는 표시이고, OpenRouter는 그 표시를 떼고 같은 무료 모델로 보낸다. 끝에 :free 가 없는 모델은 이 목록에 넣지 않는다.

6. 설정이 비어 있을 때

다음처럼 나오면 settings.json 이 아직 없는 것이다. 2장의 스크립트를 실행한다.

claude --version
2.1.227 (Claude Code)
BASE=
MODEL=
KEY_SET=False

claude --version 이 2.1.227을 출력하는 것은 프로그램 설치가 끝났다는 뜻이고, 무료 키 연결이 끝났다는 뜻은 아니다.
