OpenCode 무료 AI 자동셋팅

Cursor에서 확인한 내용. 작성일 2026-11-09 (한국 시간). 이 문서에는 API 키 값을 넣지 않는다.

PC의 D:\ai\AI 셋팅\free AI 방법 은 이 작업 환경에 연결되어 있지 않다. 기존 HTML을 열어서 합치지 못했으므로, 이 파일이 Cursor 세션에서 확인한 절차 전체다. 이 파일을 그 폴더에 복사해 기존 문서와 함께 두면 된다.

1. 버전

opencode --version 이 1.18.23 이면 업데이트가 적용되지 않은 상태다. 1.18.23은 OpenCode 1 패키지 opencode-ai 다. 그 줄의 최신은 1.19.5이고, 현재 쓸 버전은 다른 패키지인 2.2.6 (@opencode/cli) 이다. 1.x 안의 업데이트 버튼은 2.x로 넘어가지 못한다.

OpenCode 창을 모두 닫고 PowerShell에서 실행한다.

npm uninstall -g opencode-ai
npm install -g @opencode/cli
opencode --version

2.2.6 이 나오면 새 터미널을 열고 opencode 를 다시 실행한다. 그대로 1.18.23이면 예전 opencode.exe 가 먼저 잡힌 것이다.

Get-Command opencode | Format-List Source,Version

2. Cline Free가 /connect에 없는 이유

플러그인 opencode-cline-free 0.9.0은 OpenCode 2가 켜질 때만 Cline Free 를 등록한다. 제공자 ID는 cline-free 이고, 화면에 보이는 이름은 Cline Free 다. 0.7.0부터 1.x용 등록 코드는 빠져 있고, 1.18.23은 예전 1.x 최소 조건 1.18.29보다 낮다. 그래서 플러그인 파일을 넣어 두어도 1.18.23의 /connect 에는 나오지 않는다.

2.2.6에서 플러그인을 실제로 로드하면 /connect 목록에 Cline Free가 들어온다. 로그인 방법은 세 가지다.

  • Cline account (free models, recommended) — 브라우저 기기 코드
  • Reuse Cline CLI login — 이 PC에서 이미 cline auth 를 한 경우
  • Cline token (manual) — workos: 로 시작하는 토큰

목록에는 제공자가 약 240개 있다. /connect 를 연 다음 cline 을 입력해 걸러야 Cline Free가 보인다.

3. 플러그인 설치

사용자 PC에서 아래 명령은 성공했다. 설정 파일은 C:\Users\USER\.config\opencode\opencode.json 이다.

opencode plugin add github:itsyasirkhandev/opencode-cline-free
opencode service restart

opencode service restart 는 Windows에서 http://127.0.0.1:28894 를 출력한다. 그 직후 opencode plugin list 가 No plugins found 라고 나와도, 설치 실패로 단정하지 않는다. 같은 순서를 OpenCode 2.2.6에서 재현했을 때, 재시작 직후 목록은 비어 있고 약 3초 뒤에 플러그인이 보였다.

opencode plugin list

정상 목록:

ID          VERSION  SOURCE
cline-free  f36319a  github:itsyasirkhandev/opencode-cline-free

3초 뒤에도 비어 있으면 설정 파일을 확인한다. plugins 안에 github:itsyasirkhandev/opencode-cline-free 가 있어야 한다.

Get-Content "$env:USERPROFILE\.config\opencode\opencode.json"

그다음 새 터미널에서 opencode 를 실행하고 /connect 에서 cline 을 입력한다.

4. Cline 계정 로그인

Cline 계정이 없으면 브라우저에서 https://app.cline.bot 에 가입한다. 키 모음 파일에는 Cline 로그인이 없다.

  1. OpenCode를 완전히 끄고 다시 실행한다.
  2. /connect 를 입력한다.
  3. Cline Free 를 선택한다.
  4. Cline account (free models) 를 선택한다.
  5. o 는 주소를 브라우저로 열고, c 는 코드를 복사한다.
  6. 브라우저에서 Cline 계정으로 로그인한 뒤 Confirm 또는 Approve를 누른다.
  7. 터미널로 돌아오면 연결이 끝난다. 계정 이름은 이메일 @ 앞부분이다.

연결 후 /models 에서 cline-free/ 로 시작하는 모델을 고른다. 계정을 더 넣으려면 /connect → Cline Free를 다시 실행한다. 같은 계정이면 기존 항목이 갱신되고, 다른 계정이면 목록에 추가된다.

이 PC에서 이미 cline auth 로 CLI에 로그인했다면 Reuse Cline CLI login 을 고르고 확인만 한다. 토큰을 가지고 있다면 Cline token (manual) 에 workos: 토큰을 붙여 넣는다. 잘못된 토큰은 첫 요청에서 실패한다.

5. openrouter-free 는 별도 도구

haengsun1009-ux/openrouter-free 는 OpenCode 2 위에서 free/auto 만 쓰는 라우터다. Windows 설치는 저장소를 받은 뒤 다음을 실행한다. Node.js 22.18 이상과 OpenCode 2가 먼저 있어야 한다.

git clone https://github.com/haengsun1009-ux/openrouter-free.git
cd openrouter-free
powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1

새 터미널에서 확인한다.

opencode-free --version
node "$HOME\.config\opencode\free-router\rank.mts" --status

허용 목록은 OpenCode Zen, OpenRouter :free, NVIDIA, Z.AI, ModelScope, Mistral Experiment, Groq, Cerebras, Google Flash/Gemma 이다. Anthropic/Claude는 그 목록에 없다. opencode-free 를 켜면 세션 모델이 다시 무료 모델로 바뀐다. 일반 opencode 설정은 그대로다.

키는 %USERPROFILE%\.config\opencode\free-router\providers.env 에만 넣는다. 채팅이나 이 HTML에 붙이지 않는다. 설치 스크립트는 기존 config.json, pins.json, 키, 상태를 덮어쓰지 않는다.
